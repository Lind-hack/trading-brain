# ── Market Brain (paper-trading analysis engine) ────────────────────────────────
# Append to the ROOT crontab (additive — leaves stock/futures engines untouched):
#   crontab -l | cat - /root/trading-brain/vps/crontab.txt | crontab -
#
# TIMES ARE UTC. Not by preference — Debian's cron (3.0pl1) has no CRON_TZ; only cronie does.
# Setting it here would be read as an ordinary environment variable and every job would still
# fire on UTC, four or five hours off the session it was meant to track. Verified on this box:
#   grep -ac CRON_TZ /usr/sbin/cron  ->  0
#
# So cron does not try to know when the market is open. It offers candidate times, wide enough
# to cover both halves of the year, and brain/market_hours.py decides:
#
#   EDT (Mar–Nov)   session 13:30–20:00 UTC
#   EST (Nov–Mar)   session 14:30–21:00 UTC
#
# A gated-out run prints "[gate] skipping ..." , writes a heartbeat and exits 0. Weekends,
# holidays and 13:00 ET half-days are all handled there, not here.
#
# The anchors and the weekly recap are offered TWICE, an hour apart, because only one of the two
# is inside the window in any given DST regime. In the other regime both are legal, so
# brain/runlog.py records the first success and the second tick skips itself. That pair — gate
# plus run-log — is what replaces CRON_TZ.
#
# The stock engine runs at :07/:22/:37/:52; the brain deliberately uses :03/:33/:15/:35/:45 to
# avoid flock/CPU collisions. Each job:
#   - flock -n so a slow run never overlaps the next tick
#   - sources /root/.secrets/signal.env for keys
#   - uses the repo venv python
#   - logs to /root/signal-deck-logs/brain-*.log
BRAIN=/root/trading-brain
PY=/root/trading-brain/.venv/bin/python
ENVF=/root/.secrets/signal.env
LOGD=/root/signal-deck-logs

# Intraday screen every 30 min. 12:00–21:59 UTC spans the session in both regimes (08:03–17:33 ET
# in summer, 07:03–16:33 ET in winter); the gate keeps only the ticks between the real open and
# the real close, so roughly thirteen of the twenty offered ticks run on a normal day and none
# run on a half-day afternoon. Deep run only if the screener or the Haiku news pass fires.
3,33 12-21 * * 1-5   flock -n /tmp/brain-cycle.lock  bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --cycle    >> $LOGD/brain-cycle.log 2>&1'

# Pre-market anchor — 08:35 ET summer / 08:35 ET winter, whichever of the two lands in the gate's
# 3.5h pre-open window without the session already being open.
35 12 * * 1-5        flock -n /tmp/brain-anchor.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --anchor pre   >> $LOGD/brain-anchor.log 2>&1'
35 13 * * 1-5        flock -n /tmp/brain-anchor.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --anchor pre   >> $LOGD/brain-anchor.log 2>&1'

# Midday anchor — one tick is enough: 16:33 UTC is 12:33 ET in summer and 11:33 ET in winter, and
# both are inside regular trading hours.
33 16 * * 1-5        flock -n /tmp/brain-anchor.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --anchor mid   >> $LOGD/brain-anchor.log 2>&1'

# Close anchor — 20:15 UTC is 16:15 ET in summer (after the close, runs) and 15:15 ET in winter
# (still trading, gated out); 21:15 UTC is the reverse. On a half-day both are inside the 4h
# post-close window, and the run-log lets only the first through.
15 20 * * 1-5        flock -n /tmp/brain-anchor.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --anchor close >> $LOGD/brain-anchor.log 2>&1'
15 21 * * 1-5        flock -n /tmp/brain-anchor.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --anchor close >> $LOGD/brain-anchor.log 2>&1'

# Weekly recap — after the week's last close. Offered every weekday afternoon; the gate accepts
# exactly one day, the last trading day of the week. That is normally Friday, but in Good Friday
# week it is Thursday and the recap moves with it on its own.
45 20 * * 1-5        flock -n /tmp/brain-weekly.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --weekly-review >> $LOGD/brain-weekly.log 2>&1'
45 21 * * 1-5        flock -n /tmp/brain-weekly.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --weekly-review >> $LOGD/brain-weekly.log 2>&1'

# Week-ahead digest — the one email that arrives before the week starts, and the first of the two
# weekly re-scores of the long-term thesis board. Since 2026-08-01 it lands the EVENING BEFORE the
# week's first session rather than that morning: Lind asked for the weekend to carry the recap and
# the week ahead and nothing else, and a preview read the night before is worth more than one that
# arrives ninety minutes before the bell.
#
# That first session is Monday normally, Tuesday when MLK Day, Presidents' Day, Memorial Day or
# Labor Day takes the Monday — so the eve moves too, and the weekday ticks below cover it. The
# gate accepts exactly one day either way. On the first session's morning the pre-market anchor
# stands aside, so Lind gets one email rather than two.
#
# 21:05 UTC on a Sunday is 17:05 ET in summer and 16:05 ET in winter — still Sunday in Eastern,
# which is the only thing the gate checks for the eve. 22:05 is a retry, not a DST pair.
#
# The weekday ticks are retries as well, one on the eve of a holiday-shifted week and one on the
# first morning itself, both inside the gate's 5h pre-open window. Nothing here can double-send:
# runlog stamps the digest with the ISO week it is ABOUT rather than the day it ran, so a Sunday
# success closes the window for every later tick — including Monday's, which falls in a different
# calendar day but the same target week.
5 21 * * 0           flock -n /tmp/brain-digest.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --digest >> $LOGD/brain-digest.log 2>&1'
5 22 * * 0           flock -n /tmp/brain-digest.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --digest >> $LOGD/brain-digest.log 2>&1'
5 21 * * 1-5         flock -n /tmp/brain-digest.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --digest >> $LOGD/brain-digest.log 2>&1'
5 12 * * 1-5         flock -n /tmp/brain-digest.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --digest >> $LOGD/brain-digest.log 2>&1'
5 13 * * 1-5         flock -n /tmp/brain-digest.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --digest >> $LOGD/brain-digest.log 2>&1'

# ── the crypto book — the one track that does run overnight and at weekends ─────
# Separate lock, separate log, separate ledger (brain-memory/PORTFOLIO_CRYPTO.json). It shares
# nothing with the jobs above except the box, so a stuck equity cycle cannot hold it up and vice
# versa — /tmp/brain-crypto.lock is its own file on purpose.
#
# --crypto-cycle routes around market_hours.gate() and calls crypto_gate() itself, which answers
# "always". That is the whole point: this venue has no bell, no weekend and no holiday, and every
# hour the equity book is shut is an hour this one still trades.
#
# It has to run through the night for a second reason, and it is the expensive one to get wrong:
# the scalp time stop only fires inside a cycle. A 24-hour scalp filled at 03:00 UTC expires at
# 03:00 UTC the next day, and if nothing is running at 03:00 there is no code path anywhere in
# this system that closes it. Thinning this schedule overnight quietly turns a one-day trade back
# into an open-ended one.
#
# :18 keeps it clear of the stock engine (:07/:22/:37/:52) and of the brain's own equity cycle
# (:03/:33). Deep run only when the screener or the Haiku news pass fires, same as equities.
#
# Hourly, not half-hourly, since 2026-07-28. It ran :18/:48 — 336 cycles a week, each one paying
# for a Haiku news pass — and the token bill was the complaint. Halving the cadence halves that
# pass without touching the paragraph above: hourly is still often enough to enforce a -15% hard
# stop and a 24-hour scalp clock, which were never checked tick-by-tick anyway. Thinning it
# *further* is where the warning above starts to bite, so treat hourly as the floor.
18 * * * *        flock -n /tmp/brain-crypto.lock bash -lc '. $ENVF; cd $BRAIN && $PY market_brain.py --crypto-cycle >> $LOGD/brain-crypto.log 2>&1'

# Nothing else runs overnight or at the weekend, with one deliberate exception: the Sunday
# week-ahead digest above. For the equity book the market is shut, so the brain is too — the
# weekend carries the Friday recap and the Sunday preview, and nothing else.
